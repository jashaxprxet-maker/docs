# Battle Royale MVP (Phaser + Vite)

Run locally:

```bash
cd game
npm install
npm run dev
```

Open the URL shown (default `http://localhost:5173`).

Controls:
- Move: WASD or Arrow Keys
- Aim/Shoot: Mouse (hold to autofire)
- Restart: R (after win/lose)

Gameplay:
- 20 enemies chase you and occasionally shoot.
- A safe zone shrinks over time; outside it you take damage.
- Eliminate all enemies to win.
